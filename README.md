# Chief

Chief — your project chief of staff.

A web app for project managers: each morning it assembles one daily update for all your
projects from developer EODs in Slack, your to-dos, and Fathom client-call notes. You review,
edit, and post it. Nothing is sent without your approval.

- **PROGRESS.md** — what's built and what's next
- **SETUP_GUIDE.md** — step-by-step setup of every outside service
- **supabase/migrations/** — the database structure

Tech: Next.js, TypeScript, Tailwind, Supabase, Netlify.
